第 5 章｜部署 LINE Bot 至 Vercel

5-2 部署、Webhook 與驗證

確認 Python Deployment 為 Ready，把 Production Domain 加上 /callback 設為 LINE Webhook，再用三個正式指令與一般文字驗證。

進階篇12 分鐘完整串接

完成 Vercel 部署

  1. Redeploy

    確認六個 Environment Variables 都已儲存，到 Project → Deployments → 最新一筆 → Redeploy。

    開啟 Vercel

  2. 確認 Deployment Ready

    等待最新 Deployment 顯示 Ready。這是部署成功證據；目前 Python 程式沒有提供用 GET 開啟網址的健康檢查頁。

  3. 複製 Production Domain

    在最新 Deployment 複製類似 https://line-project-memory-bot.vercel.app 的 Production Domain。

設定 LINE Webhook

  1. 組合 Webhook URL

    正式 Webhook 路徑固定為 /callback：

    替換成你的 Production Domain
    https://你的-project.vercel.app/callback

  2. 貼入 LINE Developers

    回 Channel → Messaging API → Webhook settings → Edit，貼上完整網址並儲存。

    LINE Developers Console

  3. Verify 並啟用 Webhook

    按 Verify，成功應顯示 Success；再將 Use webhook 設為 Enabled。

  4. 確認允許加入群組

    確認 Allow bot to join group chats 已設為 Enabled。

測試順序

  1. 把 Bot 加入測試群組

    使用 Messaging API 頁面的 QR code 加官方帳號好友，再把 Bot 邀入測試群組。

  2. 設定群組收件信箱

    在群組輸入：

    替換成自己的收件信箱
    #設定信箱 自己的信箱

    Bot 應回覆已設定目前聊天室的紀錄收件信箱。

  3. 查看群組收件信箱

    輸入 #查看信箱，確認 Bot 回覆剛才設定的地址。

  4. 送出一般文字

    輸入「測試專案：第一版 10/20 完成」。只有這則一般文字應寫入 messages；三個控制指令不會寫入。

  5. 檢查 groups 與 messages

    groups 應自動出現目前群組的 group_id、group_name、receiver_email；messages 應出現一般訊息，且新訊息的 sent 是 FALSE。

如何驗證成功

  • 六個環境變數填完後已 Redeploy，Deployment 顯示 Ready
  • Webhook URL 是 HTTPS 且以 /callback 結尾
  • LINE Developers Verify 顯示 Success，Use webhook 已開啟
  • Allow bot to join group chats 已開啟
  • #設定信箱 與 #查看信箱 有正確回覆
  • groups 自動出現群組與收件信箱
  • messages 只出現一般訊息，控制指令沒有寫入，新訊息 sent = FALSE
修改變數後一定要 Redeploy新值不會回頭改變已存在的 Deployment。更新後重新部署，確認 Ready，再回 LINE Developers Verify。
