第 5 章｜部署 LINE Bot 至 Vercel

5-2 部署、Webhook 與驗證

確認 Python Deployment 為 Ready，把 Production Domain 加上 /callback 設為 LINE Webhook，再用三個正式指令與一般文字驗證。

進階篇12 分鐘完整串接

完成 Vercel 部署

  1. Redeploy

    開啟 Vercel Dashboard → 選擇 5-1 的 Project → Deployments → 最新一筆右側省略號 → Redeploy → 確認視窗再按 Redeploy。若 Environment Variables 儲存後出現直接 Redeploy 的提示，也可使用該按鈕。

    開啟 Vercel

  2. 確認 Deployment Ready

    等待最新 Deployment 顯示 Ready。若顯示 Error，點進該 Deployment → Logs／Deployment Logs，查看最新 Function 錯誤，回 Settings 修正後再 Redeploy。

  3. 複製穩定 Production Domain

    進入 Project → Settings → Domains，找到標示 Production 或主要網域的 *.vercel.app Domain → 按複製，例如 https://line-project-memory-bot.vercel.app。若清單未包含 https://，組合 Webhook 時自行補上。不要使用每次 Deployment 產生的 Preview／Deployment URL。

    你現在應該看到最新 Deployment 是 Ready，你也已取得穩定 Production Domain。直接打開根網址可能看到 404，因為目前程式沒有 GET / health page；這不代表 Bot 部署失敗。

設定 LINE Webhook

  1. 組合 Webhook URL

    把剛複製的 Vercel Production Domain 末尾斜線移除，再加上固定路徑 /callback。結果必須是一條 HTTPS 網址：

    替換成你的 Production Domain
    https://你的-project.vercel.app/callback

  2. 貼入 LINE Developers

    開啟 LINE Developers Console → 4-2 選定的 Provider → 對應 Messaging API Channel → Messaging API 分頁 → Webhook settings → Edit → 貼上完整 https://…/callback → Save。

    LINE Developers Console

  3. Verify 並啟用 Webhook

    確認網址已儲存 → 按 Verify → 等待結果顯示 Success → 再把 Use webhook 設為 Enabled。若 Verify 失敗，先檢查 Deployment Ready、六個變數與網址末尾的 /callback，不要反覆重新發行 token。

  4. 確認群組權限

    仍在 Messaging API 分頁，確認 Allow bot to join group chats = Enabled。

    你現在應該看到Webhook URL 是 Vercel Production Domain + /callback、Verify 顯示 Success、Use webhook = Enabled，群組加入權限也為 Enabled。

測試順序

練習案例以下訊息延續虛構的「活動籌備專案」，不代表任何真實工作紀錄。

  1. 把 Bot 加入測試群組

    在 Messaging API 分頁找到 QR code → 用 LINE 掃描並加官方帳號好友 → 開啟準備好的測試群組 → 群組選單 → 邀請成員 → 選擇剛加入的 Official Account → 邀請。加入時的 join 會觸發歡迎訊息，但不會寫入 messages。

  2. 設定群組收件信箱

    在群組輸入下列格式，將 placeholder 換成實際可收信地址；使用半形 #，指令後輸入一個一般半形空格：

    替換成自己的實際收件信箱
    #設定信箱 <你的實際 Email>

    Bot 應回覆已設定目前群組的紀錄收件信箱；這個控制指令會建立／更新 groups 並設定 receiver_email，但不寫入 messages。

  3. 查看群組收件信箱

    輸入 #查看信箱，確認 Bot 回覆剛才設定的地址。

  4. 送出一般文字

    輸入「活動籌備專案：場地確認期限改為 4/21，負責人仍為活動窗口。」只有這則新的非重複群組文字應寫入 messages；它也可能確保／更新目前群組的 groups 資料，但不會自行設定 receiver_email。三個控制指令都不會寫入 messages。

  5. 檢查 groups 與 messages

    開啟 4-3 的 Google Sheet → groups 應有目前群組的 group_id、group_name、receiver_email；切到 messages 應出現一般訊息，且新訊息的 sent 是 FALSE。

    你現在應該看到LINE 有 Bot 回覆；Sheets 的 groups 有一列群組設定，messages 有一列一般文字且 sent = FALSE。控制指令本身沒有出現在 messages。

如何驗證成功

  • 六個環境變數填完後已 Redeploy，Deployment 顯示 Ready
  • Webhook URL 使用穩定 Production Domain、是 HTTPS 且以 /callback 結尾
  • LINE Developers Verify 顯示 Success，Use webhook 已開啟
  • Allow bot to join group chats 已開啟
  • #設定信箱 與 #查看信箱 有正確回覆
  • groups 已出現群組與收件信箱
  • 群組新文字成功寫入 messages，控制指令沒有寫入，新訊息 sent = FALSE
正式判定方式以 Deployment 顯示 Ready、LINE Verify 顯示 Success、群組新文字成功寫入 Sheets 三項為準；根網址 404 不是失敗證據。修改變數後一定要 Redeploy。
