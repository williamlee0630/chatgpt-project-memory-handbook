第 2 章｜建立 ChatGPT 整理環境

2-1 ChatGPT 專案與來源設定

第一次使用 ChatGPT Project 時，請依序完成 Project、固定指示、來源連線與專案主對話；每一步都附有可核對的畫面結果。

基礎篇7 分鐘必要

開啟 ChatGPT開啟 Google Drive開啟 Gmail

本課統一使用 ChatGPT 網頁版本課後續 ChatGPT 操作統一以網頁版示範。請使用 Chrome 或 Edge 開啟 ChatGPT 網頁版並登入。若你平常使用 ChatGPT 桌面 App，也可以繼續使用，但按鈕位置與部分功能可能不同；為了與影片及講義畫面一致，建議上課時使用網頁版。
介面名稱與可用性可能不同本課統一寫作「Plugins／Apps（依目前介面顯示名稱為準）」；部分帳號也可能顯示 Connectors。可用性會受 plan、帳號、region、workspace、role 與管理員政策影響。沒有看到相同入口不代表你操作錯誤，請使用本頁的人工 fallback，也不要繞過組織政策。

建立「工作訊息整理」專案並加入固定指示

  1. 開啟 ChatGPT 網頁版

    使用 Chrome 或 Edge 開啟 chatgpt.com，登入你準備用於本課的 ChatGPT 帳號。若左側欄收起，先按左上角的側欄按鈕展開；後續會從這裡進入 Project 與專案主對話。

    開啟 ChatGPT

    你現在應該看到瀏覽器網址是 chatgpt.com，右上角帳號是你要用於本課的帳號，左側欄已展開。

  2. 進入專案總覽並新增專案

    在 ChatGPT 左側欄點選 專案，進入專案總覽頁面 → 點右上角的 新增。畫面接著會開啟「建立專案」視窗。

    你現在應該看到「建立專案」視窗中有「專案名稱」欄位與記憶設定。

  3. 輸入示範名稱並建立 Project

    在「專案名稱」輸入 工作訊息整理。這是本課用來集中固定規則、來源與工作記憶的 ChatGPT Project 容器。

    名稱可以自行設定「工作訊息整理」只是本課程的示範名稱，不是系統規定名稱。你可以依自己的工作、團隊或專案需求自行命名，例如「工作訊息整理」「行銷專案整理」「畢業專題」或「產品開發紀錄」。

    本課程建議選擇 僅限專案的記憶（Project-only memory），讓這個 Project 的工作脈絡集中在專案內，避免其他聊天的內容影響整理結果；但 Project-only memory 不代表搜尋到的每筆來源都屬於目前實際專案，仍須通過 Prompt 的專案相關性判斷。確認名稱與記憶設定後，點擊 建立專案。

    你現在應該看到建立完成後，左側欄的專案區出現「工作訊息整理」。

  4. 進入並確認 Project

    進入剛建立的 工作訊息整理 Project；若建立後沒有自動開啟，就從左側欄點選它。請看頁面標題或側欄選取狀態，確認目前顯示的 Project 名稱是「工作訊息整理」。

    如何判斷位置正確你現在是在 Project 裡，而不是一般 ChatGPT 對話；畫面能看出「工作訊息整理」是目前所在位置，之後在這裡建立的聊天才會套用同一組 Project instructions 與來源。

  5. 加入 Project 固定指示

    進入專案後，點右上角 「⋯」 → 專案設定（Project settings） → 找到 專案指示（Project instructions）。複製下方 Prompt 1 → 完整貼入專案指示 → 按 儲存。

    不要貼錯位置Project instructions 不是一般聊天訊息。請貼在專案設定中的指示欄位，不要貼到頁面下方的聊天輸入框；這段規則只設定一次。
    你現在應該看到重新開啟專案設定時，專案指示仍保留「專案工作記憶助理」與來源判斷規則。完成後，這個 Project 會使用本課設定的固定整理規則，後續再於其中進行會議紀錄與 LINE 紀錄的跨來源整理。

  6. 連接 Google Drive 與 Gmail

    在 ChatGPT 網頁版開啟帳號選單 → Settings／設定 → Plugins／Apps（依目前介面顯示名稱為準）。有些帳號也會在左側欄直接顯示相同入口。搜尋 Google Drive → 開啟結果 → 按 Install／安裝 或加號；需要授權時按 Connect／連接 → 登入存放 Tactiq 完整會議逐字稿的 Google 帳號 → 檢查權限 → 按 Allow／允許。

    回到相同入口搜尋 Gmail，依相同步驟連接會收到 LINE Bot [LINE紀錄] 的帳號。Google Drive 用於讀取 Tactiq 建立的完整會議逐字稿；Gmail 是進階流程讀取 LINE Bot 工作紀錄的來源。

    先確認 Drive 帳號先確認 Gmail 帳號

    你現在應該看到Google Drive 與 Gmail 都顯示已安裝／已連接，帳號也正確。若方案、帳號、地區、workspace 或管理員政策未提供其中一項，畫面可能沒有 Install 或 Connect；這不代表你操作錯誤。

  7. 在這個 Project 裡建立新的 Chat

    回到左側欄的 Projects／專案 → 工作訊息整理，在這個 Project 裡按 New chat／新增聊天。不要從一般 ChatGPT 首頁建立普通聊天。每一個實際工作專案建議使用獨立主對話，不要把網站改版、活動籌備與其他專案混在同一個聊天裡。

    你現在應該看到新的空白聊天列在「工作訊息整理」之下，而不是一般聊天列表。

  8. 送出第一則訊息，再重新命名

    先在新聊天送出一則簡短訊息，例如：「我要用這個對話整理網站改版專案的工作記憶；稍後會提供來源與日期範圍。」第一次送出訊息後，開啟對話名稱旁的選單 → 選 Rename／重新命名 → 建議使用「專案名稱｜工作記憶」格式。

    網站改版專案｜工作記憶 是範例名稱；請換成你目前實際工作的專案名稱。若 ChatGPT 自動產生的名稱已經足夠清楚，也可以保留。

    你現在應該看到「工作訊息整理」之下出現一個只服務單一實際專案的主對話；3-1 會回到這個主對話執行 Prompt 2。

驗證來源真的能讀取

  1. 建立來源連線測試對話

    為避免測試內容混入正式專案主對話，可在「工作訊息整理」內另開一個暫時聊天，命名為「來源連線測試」。測完後保留或刪除都不影響主流程。

  2. 實際讀取 Drive

    先到 Google Drive 記下一份你確定存在、可安全測試的文件名稱。回到來源連線測試對話 → 選用 Google Drive → 輸入：「請找出〈完整檔名〉，實際打開內容，告訴我第一個標題。」若只回傳檔名或搜尋摘要，追問「請讀取文件正文後回答」。

    你現在應該看到回答包含只有實際打開正文才能知道的內容。進階流程會用同一連線讀取 Tactiq 逐字稿。

  3. 實際讀取 Gmail

    先到 Gmail 記下一封可安全測試的郵件主旨；若尚未完成 LINE Bot，可先用一般測試信。回到相同測試對話 → 選用 Gmail → 輸入：「請找出主旨為〈完整主旨〉的郵件，實際打開正文，告訴我第一句。」完成第 6 章後，再以主旨包含 [LINE紀錄] 的郵件重測。

    你現在應該看到回答包含 Email 正文資訊。若顯示查無資料，先核對帳號與搜尋條件；若顯示無權限，這是「無法存取」，不可當成「沒有資料」。

無法使用 Plugins／Apps 時

基礎版仍能完成課程：從 Drive 下載／複製 Tactiq 逐字稿，並在 3-1 將逐字稿與 LINE TXT 附加到專案主對話；需要使用 Gmail 內容時，開啟郵件後手動提供要整理的正文。上傳前請依資料政策移除不必要的敏感資訊。

  • 示範 Project「工作訊息整理」已建立、選擇 Project-only memory，並能從左側欄重新開啟
  • Project instructions 已儲存 Prompt 1，且沒有誤貼到聊天輸入框
  • 實際專案已有獨立主對話，例如「網站改版專案｜工作記憶」
  • Drive 測試能實際打開並讀取內容，或已決定改用手動提供
  • Gmail 測試能實際打開並讀取內容，或已決定改用手動提供
  • 任一來源失敗時已說明原因，不得假裝已成功
