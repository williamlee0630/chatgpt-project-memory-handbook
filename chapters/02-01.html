第 2 章｜建立 ChatGPT 整理環境

2-1 ChatGPT 專案與來源設定

建立「專案工作記憶」Project、貼上固定指示，並用一份確定存在的 Drive 文件與 Gmail 郵件驗證帳號真的讀得到內容。

基礎篇7 分鐘必要

開啟 ChatGPT開啟 Google Drive開啟 Gmail

介面名稱可能不同ChatGPT 的整合入口可能顯示 Plugins、Apps 或 Connectors。可用性也會受 plan、region、workspace、role 與管理員政策影響。請依你目前畫面的同義入口操作；若沒有該功能，使用本頁最後的手動方式，不要繞過組織政策。

建立 Project 與固定規則

  1. 新增 Project

    開啟 chatgpt.com → 登入 → 在左側欄找到 New project／新增專案 → 輸入名稱 專案工作記憶 → 按 Create／建立。若左側欄收合，先按左上角選單展開。

    開啟 ChatGPT

    你現在應該看到左側欄出現「專案工作記憶」，點開後進入專案頁；之後 3-1 的專案主對話會建立在這裡。

  2. 加入 Project 固定指示

    在「專案工作記憶」頁開啟專案名稱旁的選單。依介面版本選 Project settings／專案設定 或 Edit project／編輯專案 → 找到 Instructions／Project instructions → 複製下方 Prompt 1 → 完整貼入 → 按 Save／儲存。顏色、圖示等外觀欄位可維持預設。

    你現在應該看到重新開啟專案設定時，Instructions 仍保留「專案工作記憶助理」與來源判斷規則。這段只設定一次，不要每次對話重貼。

連接 Google Drive 與 Gmail

  1. 設定資料來源

    在 ChatGPT 開啟 Plugins／Apps；若入口在工具選單，先開一個測試對話再按輸入框旁的工具按鈕。搜尋 Google Drive → 開啟結果 → 按 Install／安裝 或加號；需要授權時按 Connect／連接 → 登入存放 Tactiq 文件的 Google 帳號 → 在 Google 授權頁檢查帳號與權限 → 按 Allow／允許。

    回到相同入口搜尋 Gmail，用同樣步驟 Install → Connect → 登入 → Allow。請連接會收到 [LINE紀錄] 的帳號；不要只看「Connected」就當作已能讀取。

    先確認 Drive 帳號先確認 Gmail 帳號

    你現在應該看到Google Drive 與 Gmail 都顯示已安裝／已連接，且帳號是你預期使用的 Google 帳號。工作區管理者若停用其中一項，畫面可能不會出現 Install 或 Connect。

  2. 實際讀取 Drive

    先到 Google Drive 記下一份你確定存在、可安全測試的文件名稱。回 ChatGPT 的「專案工作記憶」→ 建立一個暫時的「來源連線測試」對話 → 選用 Google Drive app → 輸入：「請找出〈完整檔名〉，實際打開內容，告訴我第一個標題。」若只回傳檔名或搜尋摘要，追問「請讀取文件正文後回答」。

    你現在應該看到回答包含只有打開正文才能知道的內容，而不只是文件名稱。進階流程之後會用同一連線讀取 Tactiq 完整逐字稿。

  3. 實際讀取 Gmail

    先到 Gmail 記下一封可安全測試的郵件主旨；若尚未完成 LINE Bot，可先用任何測試信。回到同一測試對話 → 選用 Gmail app → 輸入：「請找出主旨為〈完整主旨〉的郵件，實際打開正文，告訴我第一句。」完成第 6 章後再以主旨包含 [LINE紀錄] 的郵件重測。

    你現在應該看到回答包含 Email 正文資訊。若顯示查無資料，先核對帳號與搜尋條件；若顯示無權限，這是「無法存取」，不可當成「沒有資料」。

無法使用 Apps／Plugins 時

基礎版仍能完成課程：從 Drive 下載／複製 Tactiq 逐字稿，並在 3-1 將逐字稿與 LINE TXT 附加到專案主對話。Gmail 郵件則開啟後手動提供需要整理的正文。上傳前依資料政策移除不必要的敏感資訊。

  • 「專案工作記憶」已建立並可從左側欄重新開啟
  • Project instructions 已儲存 Prompt 1
  • Drive 測試能實際打開並讀取內容，或已決定改用手動提供
  • Gmail 測試能實際打開並讀取內容，或已決定改用手動提供
  • 任一來源失敗時已說明原因，不得假裝已成功
