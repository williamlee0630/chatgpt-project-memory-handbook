第 2 章｜建立 ChatGPT 整理環境

2-1 ChatGPT 專案與來源設定

第一次使用 ChatGPT Project 時，以「活動籌備」這項實際工作建立獨立 Project，設定固定指示並驗證來源。3-1 才會建立專用的工作記憶對話。

基礎篇7 分鐘必要

ChatGPT Web 備用入口開啟 Google Drive開啟 Gmail

本課主要使用 ChatGPT Desktop App本課後續 ChatGPT 操作主要以 Desktop App 示範。使用 Desktop App 可以在同一套環境中完成 ChatGPT Project、來源連線與工作記憶整理，進入選用的 Skill／Codex 進階內容時也能沿用主要操作環境。若目前無法安裝 Desktop App，也可以使用 ChatGPT Web 完成本課大部分基礎流程；不同版本的按鈕位置與介面名稱可能略有差異，請依目前實際介面為準。
介面名稱與可用性可能不同本課統一寫作「Plugins／Apps（依目前介面顯示名稱為準）」；部分帳號也可能顯示 Connectors。可用性會受 plan、帳號、region、workspace、role 與管理員政策影響。沒有看到相同入口不代表你操作錯誤，請使用本頁的人工 fallback，也不要繞過組織政策。

建立「活動籌備」Project 並加入固定指示

  1. 開啟並登入 ChatGPT Desktop App

    開啟 ChatGPT Desktop App，登入你準備用於本課的 ChatGPT 帳號。若左側欄收起，先展開側邊欄；後續會從這裡進入 Project 與其中的對話。若目前沒有安裝 Desktop App，也可以從下方備用入口使用相同帳號完成本節操作。

    ChatGPT Web 備用入口

    你現在應該看到已登入正確的 ChatGPT 帳號，能看到 ChatGPT 主介面，且左側欄可展開並找到 Projects／專案入口。

  2. 進入專案總覽並新增專案

    在 ChatGPT 左側欄點選 專案，進入專案總覽頁面 → 點右上角的 新增。畫面接著會開啟「建立專案」視窗。

    你現在應該看到「建立專案」視窗中有「專案名稱」欄位與記憶設定。

  3. 以實際工作命名並建立 Project

    在「專案名稱」輸入 活動籌備。這個 Project 只放活動籌備這項工作的對話與資料。網站製作、研討會討論等不同工作，應各自建立「網站製作」Project、「研討會討論」Project；不要把所有工作放進同一個 Project，再用不同對話區分。

    名稱可以自行設定「活動籌備」是本課示範的實際工作名稱。做自己的工作時，請用那項工作的名稱建立 Project；一個 Project 對應一項工作。

    本課程建議選擇 僅限專案的記憶（Project-only memory），讓這個 Project 的工作脈絡集中在專案內，避免其他聊天的內容影響整理結果；但 Project-only memory 不代表搜尋到的每筆來源都屬於目前實際專案，仍須通過 Prompt 的專案相關性判斷。確認名稱與記憶設定後，點擊 建立專案。

    你現在應該看到左側欄的專案區出現「活動籌備」。

  4. 進入並確認 Project

    進入剛建立的 活動籌備 Project；若建立後沒有自動開啟，就從左側欄點選它。請看頁面標題或側欄選取狀態，確認目前顯示的 Project 名稱是「活動籌備」。

    如何判斷位置正確你現在是在 Project 裡，而不是一般 ChatGPT 對話；畫面能看出「活動籌備」是目前所在位置，之後在這裡建立的聊天會套用同一組 Project instructions；需要的來源仍須在對話中提供，或實際搜尋並讀取。

  5. 加入 Project 固定指示

    進入專案後，點右上角 「⋯」 → 專案設定（Project settings） → 找到 專案指示（Project instructions）。複製下方 Prompt 1 → 完整貼入專案指示 → 按 儲存。

    不要貼錯位置Project instructions 不是一般聊天訊息。請貼在專案設定中的指示欄位，不要貼到頁面下方的聊天輸入框；這段規則只設定一次。
    你現在應該看到重新開啟專案設定時，專案指示仍保留「專案工作記憶助理」與來源判斷規則。完成後，這個 Project 會使用本課設定的固定整理規則，後續再於其中進行會議紀錄與 LINE 紀錄的跨來源整理。

  6. 連接 Google Drive 與 Gmail

    在 ChatGPT Desktop App 開啟 Settings／設定，進入 Plugins／Apps（依目前介面顯示名稱為準）；部分帳號可能顯示 Connectors。不同版本或 ChatGPT Web 的入口位置可能略有差異，請依目前介面顯示為準。搜尋 Google Drive → 開啟結果 → 按 Install／安裝 或加號；需要授權時按 Connect／連接 → 登入存放 Tactiq 完整會議逐字稿的 Google 帳號 → 檢查權限 → 按 Allow／允許。

    回到相同入口搜尋 Gmail，依相同步驟連接會收到 LINE Bot [LINE紀錄] 的帳號。Google Drive 用於讀取 Tactiq 建立的完整會議逐字稿；Gmail 是進階流程讀取 LINE Bot 工作紀錄的來源。

    先確認 Drive 帳號先確認 Gmail 帳號

    你現在應該看到Google Drive 與 Gmail 都顯示已安裝／已連接，帳號也正確。若方案、帳號、地區、workspace 或管理員政策未提供其中一項，畫面可能沒有 Install 或 Connect；這不代表你操作錯誤。

  7. 在「活動籌備」Project 裡查找來源

    回到左側欄的 Projects／專案 → 活動籌備，在這個 Project 裡按 New chat／新增聊天，建立用來查找會議來源的對話。不要從一般 ChatGPT 首頁建立普通聊天。這個對話只用來查找原始紀錄；工作記憶會在 3-1 另建專用對話。

    你現在應該看到新的聊天列在「活動籌備」之下。

  8. 保留「查找會議原始紀錄」對話

    在新聊天查找或讀取一份會議原始紀錄後，開啟對話名稱旁的選單 → 選 Rename／重新命名 → 命名為 查找會議原始紀錄。這是 Project 裡的一個對話，不是 Project 名稱。3-1 會保留它，再新增「活動籌備｜工作記憶」對話。

    你現在應該看到「活動籌備」Project 裡保留「查找會議原始紀錄」對話；不需要刪除或改成工作記憶對話。

驗證來源真的能讀取

  1. 在既有對話驗證來源連線

    回到「活動籌備」Project 裡的「查找會議原始紀錄」對話，使用這個對話驗證來源是否真的可讀取。正式工作記憶對話會在 3-1 建立。

  2. 實際讀取 Drive

    先到 Google Drive 記下一份你確定存在、可安全測試的文件名稱。回到「查找會議原始紀錄」對話 → 選用 Google Drive → 輸入：「請找出〈完整檔名〉，實際打開內容，告訴我第一個標題。」若只回傳檔名或搜尋摘要，追問「請讀取文件正文後回答」。

    你現在應該看到回答包含只有實際打開正文才能知道的內容。進階流程會用同一連線讀取 Tactiq 逐字稿。

  3. 實際讀取 Gmail

    先到 Gmail 記下一封可安全測試的郵件主旨；若尚未完成 LINE Bot，可先用一般測試信。回到相同對話 → 選用 Gmail → 輸入：「請找出主旨為〈完整主旨〉的郵件，實際打開正文，告訴我第一句。」完成第 6 章後，再以主旨包含 [LINE紀錄] 的郵件重測。

    你現在應該看到回答包含 Email 正文資訊。若顯示查無資料，先核對帳號與搜尋條件；若顯示無權限，這是「無法存取」，不可當成「沒有資料」。

無法使用 Plugins／Apps 時

基礎版仍能完成課程：從 Drive 下載／複製 Tactiq 逐字稿，並在 3-1 將逐字稿與 LINE TXT 附加到「活動籌備」Project 的新工作記憶對話；需要使用 Gmail 內容時，開啟郵件後手動提供要整理的正文。上傳前請依資料政策移除不必要的敏感資訊。

  • 「活動籌備」Project 已建立、選擇 Project-only memory，並能從左側欄重新開啟
  • Project instructions 已儲存 Prompt 1，且沒有誤貼到聊天輸入框
  • 「活動籌備」Project 裡保留「查找會議原始紀錄」對話；工作記憶對話留到 3-1 建立
  • Drive 測試能實際打開並讀取內容，或已決定改用手動提供
  • Gmail 測試能實際打開並讀取內容，或已決定改用手動提供
  • 任一來源失敗時已說明原因，不得假裝已成功
