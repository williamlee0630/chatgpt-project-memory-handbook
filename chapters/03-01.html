第 3 章｜建立跨來源工作記憶

3-1 第一次建立工作記憶

回到第三集已建立的「活動籌備」Project，保留「查找會議原始紀錄」對話，在同一個 Project 內新增專用對話，使用 Prompt 2 建立第一版工作記憶。

基礎篇8 分鐘跨來源整理已實測
直接承接第三集第三集建立的是「活動籌備」Project。本節不重新建立 Project，也不進入其他工作的 Project。1-2 的會議逐字稿與 2-2 的 LINE TXT 都應已準備好。

ChatGPT Web 備用入口

搜尋結果只是候選搜尋到資料不代表它屬於目前專案。即使同一組人物與日期相同，也可能分別在談國際研討會、課程影片與黑客松；必須讀取正文與上下文，再通過專案相關性判斷。

在「活動籌備」Project 建立專用工作記憶對話

  1. 回到第三集建立的 Project

    開啟 ChatGPT Desktop App → 左側欄的 Projects／專案 → 選擇 活動籌備 Project。先確認 Project 裡已有「查找會議原始紀錄」對話；保留這個對話，不要刪除，也不要把它改名為工作記憶。

    你現在應該看到目前所在的 Project 名稱是「活動籌備」，原本的「查找會議原始紀錄」仍在其中。

  2. 新增專用工作記憶對話

    在「活動籌備」Project 裡按 New chat／新增聊天。不要從一般 ChatGPT 首頁新增，也不要重新建立 Project。這個新對話專門整理活動籌備的會議、LINE、待辦與決策；第一次整理完成後，再將它命名為「活動籌備｜工作記憶」。

    你現在應該看到「活動籌備」Project 裡除了原本的查找對話，又出現一個新的空白對話。
Project 與對話分工Project 用來區分不同工作；專用對話用來持續整理同一項工作的資料。之後收到新的會議或 LINE 紀錄，回到這個工作記憶對話更新即可，不必每次重新建立 Project 或工作記憶對話。Project 不會自動提供其他對話的完整內容；需要的原始資料仍要附加，或實際搜尋、開啟並讀取。

在新對話執行跨來源整理

  1. 提供基礎版檔案或選用進階來源

    基礎版：在新對話按輸入框旁的附件按鈕 → 選擇 Tactiq 會議逐字稿與 LINE TXT → 等待兩個檔名都出現在訊息列。進階版：按輸入框旁的 +／工具選單 → 開啟 Plugins／Apps（依目前介面顯示名稱為準） → 選用已連接且有存取權限的 Google Drive 與 Gmail，讓本次整理實際搜尋、開啟並讀取相關文件與郵件正文。若 ChatGPT 詢問是否允許搜尋 Project 以外的來源，確認帳號與權限無誤後再同意。

    建立 Project 或新對話本身，不會自動讀取 Google Drive、Gmail 或「查找會議原始紀錄」對話中的完整內容。若只有其中一個來源，先補齊或在 Prompt 中明確說明，不能假裝完成跨來源整理。

    你現在應該看到基礎版顯示兩個待送出的附件；進階版顯示 Google Drive 與 Gmail 可供本次對話使用。

  2. 填入專案名稱與日期範圍

    本課示範的專案名稱填「活動籌備」。做自己的工作時，換成當前 Project 對應的實際工作名稱。日期請使用來源真正涵蓋的開始與結束日期，不要沿用講義中的 placeholder，也不要把其他專案的同日資料一起帶入。

  3. 填入並送出 Prompt 2

    複製下方 Prompt 2 → 把 ＿＿＿＿專案 換成 活動籌備專案（或自己的實際專案名稱）→ 把兩個 YYYY-MM-DD 換成實際開始與結束日期 → 貼進剛才在「活動籌備」Project 新建的工作記憶對話。基礎版確認附件仍在訊息列，進階版確認來源已選用，再按送出。

建立第一版後，確認並命名對話

  1. 先確認工作與實際來源

    確認這次整理的是活動籌備。捲到「本次實際讀取的資料」，核對會議文件名稱、日期、LINE TXT 檔名或 Gmail 郵件主旨。答案只列搜尋結果、沒有正文證據時，要求重新實際打開並讀取。

  2. 核對專案相關性

    確認正式摘要只使用與活動籌備明確相關的內容；無法確認歸屬的資料應列在「需要人工確認」，明確無關資料應排除。

  3. 區分四種狀態

    「已讀取且找到相關資料」才能正常整理；「指定已發生期間內未找到相關資料」表示來源可用但沒有相關內容；「目前無法存取此來源」表示權限或連線失敗；晚於執行日的範圍則是「尚未發生」。後兩者都不能假裝已完成完整比較，未來期間也不能寫成查無資料。

  4. 檢查第一版工作記憶

    檢查 30 秒摘要、已確認決策、待辦、未決事項、決策變更、衝突提醒、需要人工確認、實際讀取資料與排除資料。重要結論仍要在 3-2 對照原始資料做人工驗收。

    你現在應該看到同一則回答清楚列出兩類來源與固定輸出；會議視為會議當下版本，LINE 視為會後補充或後續更新。

  5. 命名並保留專用對話

    取得第一版後，開啟這個新對話名稱旁的選單 → 選 Rename／重新命名 → 命名為 活動籌備｜工作記憶。請確認它列在「活動籌備」Project 之下，並保留供 3-2 驗收及日後更新；原本的「查找會議原始紀錄」也繼續保留。

這是之後持續使用的對話不要因為日期變了就另開新對話，也不要依序再跑「LINE 整理、會議整理、合併、決策、待辦」多支 Prompt。3-2 會教你在「活動籌備｜工作記憶」對話驗收並更新下一個日期範圍。

完成確認

  • 目前位於第三集建立的「活動籌備」Project，且「查找會議原始紀錄」仍保留
  • 會議紀錄與 LINE TXT 都已提供，或進階版兩個來源都已實際讀取
  • ChatGPT 已產出摘要／決策／待辦／變更／未決事項，並列出實際讀取來源
  • 新對話已命名為「活動籌備｜工作記憶」，準備在 3-2 人工驗收
