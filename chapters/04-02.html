第 4 章｜準備 LINE Bot 自動化環境

4-2 LINE Official Account 設定

依現行流程先建立 LINE Official Account、啟用 Messaging API，再到 LINE Developers Channel 取得兩個密鑰並允許 Bot 加入群組。Webhook URL 留到部署完成後再填。

進階篇5 分鐘需要 LINE 帳號

LINE Developers ConsoleOfficial Account Manager

建立 Official Account 與 Channel

  1. 建立 LINE Official Account

    先登入 Official Account Manager，建立本課測試用官方帳號。學生看到的 Bot 名稱在這裡設定。

    Official Account Manager

  2. 啟用 Messaging API

    在該 Official Account 的設定中啟用 Messaging API，依畫面選擇或建立 Provider。啟用後，系統會建立對應的 Messaging API Channel。

  3. 登入 LINE Developers

    按 Log in，使用同一個管理帳號登入，開啟剛建立的 Provider 與 LINE Developers Channel。不要從 Developers 第一個畫面直接尋找新建 Messaging API Channel 的舊流程。

    LINE Developers Console

取得兩個密鑰

  1. 複製 Channel Secret

    進入 Channel 的 Basic settings，找到 Channel secret。稍後放到 Vercel 的 LINE_CHANNEL_SECRET；複製時不要帶入前後空白。

  2. 發行 Channel Access Token

    進入 Messaging API 頁籤，找到 Channel access token。本課 Demo 按 Issue 發行 long-lived token，稍後放到 LINE_CHANNEL_ACCESS_TOKEN。

  3. 暫存位置

    先放到 Windows 的密碼管理器或未同步的臨時安全筆記。完成 Vercel 設定後刪除臨時副本。

Token 正式環境補充課程使用 long-lived token 是為了降低初學者輪替複雜度；production 應評估 LINE 建議的 short-lived、v2.1 或 stateless token 管理方式。重新發行 long-lived token 會使舊的 long-lived token 失效；更新後也要替換 Vercel 值並 Redeploy。

允許加入群組與排除自動回覆

  1. 開啟群組功能

    在 Messaging API 設定找到 Allow bot to join group chats，設為 Enabled。

  2. 調整回覆模式

    到 Official Account Manager → Settings → Response settings。啟用 Webhook；依測試需要關閉 Greeting message 與 Auto-response，避免 Bot 對每句話額外回覆。

    Official Account Manager

  3. 先不要設定 Webhook URL

    Webhook URL 要等第 5 章 Vercel Deployment 成為 Ready 並取得 Production Domain 後才有。現在不需按 Verify。

群組只能有一個 Official Account同一個 LINE 群組／多人聊天室，同一時間只能有一個 LINE Official Account。如果 Bot 無法加入，先確認群組內是否已有另一個官方帳號。本課程式只處理 group，新版 LINE room 不在正式教學範圍。

如何驗證成功

  • Channel 頁面看得到 Basic settings 與 Messaging API
  • 已取得 Channel Secret 與 Channel Access Token
  • Allow bot to join group chats 已啟用
  • 已知道如何排除 Greeting message 與 Auto-response 干擾
  • Webhook URL 尚未設定，將在 5-2 使用 /callback
不要貼真實密鑰到群組如果密鑰曾出現在公開位置，立即在 LINE Developers 重新發行／更換，並同步更新 Vercel。
