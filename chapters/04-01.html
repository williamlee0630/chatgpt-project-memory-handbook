正式學生版技術組合

程式使用 Python、Flask、Vercel、gspread、Gmail SMTP、LINE Messaging API。學生不需要自行改寫程式；ChatGPT 只在 Gmail 取得紀錄後負責整理，不會由 Bot 呼叫 ChatGPT API。

每個服務只做一件事

服務用途不負責
LINE Official Account讓 Bot 加入群組，透過 LINE Messaging API 送出事件不補抓加入前歷史
Flask Webhook／Vercel在公開 HTTPS 的 /callback 接收並驗證事件不當永久資料庫
Google Sheets／gspread保存 Bot 加入後的新文字訊息與寄送狀態不做內容判斷
Gmail SMTP按群組把尚未寄送的 LINE 紀錄寄出不接收 Tactiq Transcript
ChatGPT與 Drive 會議逐字稿合併、判斷決策與衝突不自行補缺少的資訊

Google Sheets 保存欄位

messages 依序保存：

messages 欄位
webhook_event_id	message_id	group_id	user_id	display_name	message	created_at	sent
  • webhook_event_id 用於避免 LINE Webhook redelivery 重複寫入；舊事件沒有此值時以 message_id 後備去重。
  • group_id 是多群組隔離依據，不使用可能重複或變更的群組名稱。
  • 新訊息的 sent 是 FALSE；Email 成功後才改為 TRUE，失敗維持 FALSE。正式狀態是 FALSE → TRUE。

範本的實際行為

  • 一般訊息只處理 source.type = group 且 Bot 加入群組後收到的新文字；這些文字會寫入 messages。
  • 群組的 join／memberJoined 事件會觸發歡迎訊息，但事件本身不會寫入 messages。
  • LINE 私訊、multi-person room、圖片、貼圖、檔案、語音、收回訊息、其他非文字訊息與加入前歷史，都不是本課正式處理範圍。
  • 同一隻 Bot 可加入多個群組，資料與寄信均以 group_id 隔離。
  • #設定信箱 <實際可收信 Email> 設定目前群組收件信箱；#查看信箱 查詢；#寄出紀錄 只寄出目前群組尚未寄送的訊息。
  • 三個控制指令不會寫入 messages。
  • Gmail 主旨固定為 [LINE紀錄][群組名稱] YYYY-MM-DD。
課程 Demo 安全限制本課只使用測試群組，不要直接把 Bot 加入正式客戶群、敏感工作群或含機密資訊的群組。Bot 會保存加入後的新文字；實際工作使用時必須遵守公司資料政策及適用的群組告知／授權要求。目前 Demo 沒有管理員權限驗證，群組內任何可使用控制指令的成員都可能執行 #設定信箱 或 #寄出紀錄。企業若要限制操作人，需另行實作管理員授權；本課不偷偷擴充此功能。

部署前檢查

  • 可以登入 LINE Developers 與 LINE Official Account Manager
  • 可以建立 Google Cloud 專案、服務帳號與 Google Sheet
  • Google 帳號已開啟兩步驟驗證，可建立 Gmail App Password
  • 可以登入 Vercel；學生部署主線不需要 GitHub
  • 準備兩個測試 LINE 群組；不要先用正式客戶群組
密鑰安全Channel Secret、Access Token、Service Account JSON 與 Gmail App Password 都是密鑰。只把需要的值放入 Vercel Environment Variables；JSON 不得放進 GitHub、ZIP、講義、聊天或公開畫面。
