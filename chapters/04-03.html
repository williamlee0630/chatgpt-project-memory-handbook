第 4 章｜準備 LINE Bot 自動化環境

4-3 Google Sheets 與 Gmail 設定

建立兩張工作表、Service Account 與 Gmail App Password。只建立正確表頭，不先填群組或假資料。

進階篇10 分鐘必要

新增 Google SheetGoogle Cloud ConsoleGoogle App Password

建立試算表

  1. 命名檔案

    開啟 sheets.new → 若要求登入，選擇稍後建立 Service Account 的 Google 帳號 → 在左上角點「未命名的試算表」→ 輸入 LINE 訊息整理 Bot 紀錄 → 按 Enter。

    建立試算表

  2. 建立 groups 工作表

    雙擊底部第一個分頁名稱 → 改成全小寫 groups → 點 A1 → 複製並貼上下列 Tab 分隔表頭。貼上後應剛好分成 A～C 三欄，欄位順序不可交換。

    groups!A1:C1
    group_id	group_name	receiver_email

  3. 建立 messages 工作表

    按左下角 + → 雙擊新分頁名稱 → 改成全小寫 messages → 點 A1 → 貼上下列表頭。貼上後應剛好分成 A～H 八欄，欄位順序不可交換。

    messages!A1:H1
    webhook_event_id	message_id	group_id	user_id	display_name	message	created_at	sent

  4. 只保留表頭

    groups 與 messages 名稱必須完全小寫。現在不要建立群組資料列、不要填 group ID、不要放假資料。新的非重複一般群組文字會寫入 messages；它與相關群組控制指令都可能確保／更新 groups 的群組資料，但只有你在 LINE 輸入 #設定信箱 才會設定 receiver_email。

  5. 複製 Spreadsheet ID

    點瀏覽器網址列；網址中 /d/ 與 /edit 之間的字串就是 GOOGLE_SHEET_ID。只複製這段並安全暫存，5-1 會放進 Vercel；不要複製整條網址。

    你現在應該看到檔案底部只有 groups 與 messages 兩個分頁；第 1 列分別是 3 欄與 8 欄表頭，第 2 列以下維持空白。

A. 建立 Google Cloud Project

  1. 建立／選擇 Cloud Project

    開啟 Google Cloud Console → 登入 → 頂端 Project selector／專案選擇器 → New Project → 在 Project name 輸入 LINE Project Memory。Organization／Location 若未由公司指定可維持預設 → 按 Create → 建立完成後再從 Project selector 選取它。

    建立 Cloud Project

    你現在應該看到Google Cloud Console 頂端目前選取的專案是 LINE Project Memory。這個 Project 用來啟用 Sheets API 與管理 Service Account，不是 Vercel 環境變數的值。

B. 啟用 Google Sheets API

  1. 啟用 Google Sheets API

    先確認頂端目前專案是 LINE Project Memory → 左上選單 → APIs & Services → Library → 搜尋 Google Sheets API → 點進搜尋結果 → Enable。若按鈕顯示 Manage，代表已啟用。

    你現在應該看到Google Sheets API 詳細頁顯示 API enabled／已啟用 或可按 Manage。

C. 建立 Service Account 與 JSON Key

  1. 新增 Service Account

    左上選單 → IAM & Admin → Service Accounts → 確認專案名稱 → Create service account。Service account name 輸入 line-sheet-writer → Create and continue。本課不需授予整個 Cloud Project 角色，角色欄留空 → Continue → Done。

  2. 下載並安全保存 Service Account JSON

    在 Service Accounts 清單點 line-sheet-writer 的 Email → Keys → Add key → Create new key → 選 JSON → Create。瀏覽器只會下載這個私密金鑰檔；請把它移到安全資料夾並保留原始檔名。

    如果組織禁止建立 JSON key若目前使用學校／公司管理的 Google 帳號，而且組織政策禁止建立 JSON key，建議改用自己可管理的個人 Google Cloud Project，或洽組織管理員確認權限。

    Service Account JSON 是敏感憑證，不可上傳 GitHub、不可放進課程 ZIP，也不可出現在公開畫面或聊天中。本節只下載並安全保存；5-1 建立 Vercel Project 後再轉成 Base64。

  3. 共用試算表

    用記事本打開剛下載的 JSON → 找到並複製 client_email 的值。回 Google Sheet → 右上 Share／共用 → 在新增使用者欄貼上完整 client_email → 權限選 Editor／編輯者 → 若可選，取消寄送通知 → 按 Share／Send。

    公司／學校 Google Workspace 可能禁止分享給外部 Service Account；若出現政策阻擋，必須請管理員允許或改用可授權的專案，不能靠公開連結取代。

    你現在應該看到試算表的共用清單出現 JSON 中相同的 client_email，角色為 Editor／編輯者；原始 JSON 仍安全保存在本機。

D. 設定 Gmail App Password

  1. 開啟兩步驟驗證

    Google Account → Security／安全性 → 2-Step Verification／兩步驟驗證 → 按畫面完成手機或其他驗證方式。回到安全性頁確認狀態為 On／已開啟。即使已開啟仍找不到 App Password，常見原因是 Security Key-only 驗證、公司／學校組織管理帳號限制，或已啟用 Advanced Protection。

  2. 新增 App Password

    打開 App Password 頁面 → 選擇要當寄件者的 Google 帳號 → 再次驗證身分 → 在 App name 輸入 LINE Project Memory → 按 Create／建立。

    建立 App Password

  3. 安全保存

    複製畫面顯示的 16 碼 App Password 並安全暫存；關閉視窗後通常不會再次顯示。GMAIL_ADDRESS 必須是建立這組 App Password 的寄件 Google 帳號。GMAIL_APP_PASSWORD 不是 Gmail 一般登入密碼，貼入 Vercel 前必須移除顯示用空格。若之後修改一般登入密碼，既有 App Password 可能被撤銷，需重新建立並更新 Vercel。

    你現在應該看到你已安全保存寄件 Gmail 地址與 16 碼 App Password，並知道 5-1 分別放入 GMAIL_ADDRESS 與 GMAIL_APP_PASSWORD。

完成後，你手上應有這些值

取得的項目後續使用位置
Google Sheet ID5-1 Vercel → GOOGLE_SHEET_ID
Service Account JSON原檔安全留在本機；5-1 再轉成 Base64 並放入 GOOGLE_SERVICE_ACCOUNT_BASE64
Service Account client_email只用來將 Google Sheet 分享為 Editor，不是 Vercel 環境變數
Gmail address5-1 Vercel → GMAIL_ADDRESS
Gmail App Password5-1 Vercel → GMAIL_APP_PASSWORD

如何驗證成功

  • 第一張是 groups、第二張是 messages，名稱完全小寫且欄位順序一致
  • 兩張表只有正確表頭，沒有手動群組列或假資料
  • Google Sheets API 顯示 Enabled
  • Service Account 的 client_email 是試算表編輯者，原始 JSON 已安全保存
  • 已安全取得 GOOGLE_SHEET_ID 與無空格的 Gmail App Password，準備帶到 5-1
