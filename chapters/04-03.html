第 4 章｜準備 LINE Bot 自動化環境

4-3 Google Sheets 與 Gmail 設定

建立兩張工作表、服務帳號與 Gmail App Password。這一節只做權限與資料容器，不部署程式。

進階篇10 分鐘必要

新增 Google SheetGoogle Cloud ConsoleGoogle App Password

建立試算表

  1. 命名檔案

    到 Google Sheets 新增空白試算表，左上角改名 LINE 專案工作紀錄。

  2. 建立 messages 工作表

    將第一個分頁改名小寫 messages。把以下標題貼到 A1；內容以 Tab 分隔，會自動進入 A～H 欄。

    messages!A1:H1
    receivedAt	groupId	groupName	userId	displayName	messageId	text	sentAt

  3. 建立 rooms 工作表

    按左下角 +，將新分頁改名小寫 rooms。把以下標題貼到 A1：

    rooms!A1:C1
    groupId	groupName	recipientEmail

  4. 複製 Spreadsheet ID

    網址中 /d/ 與 /edit 之間的長字串就是 ID，稍後放到 GOOGLE_SHEET_ID。不要複製整條網址。

建立服務帳號

  1. 建立／選擇 Cloud Project

    開啟 Google Cloud Console，頂端專案選單 → New Project → 輸入「LINE Project Memory」→ Create。

  2. 啟用 Google Sheets API

    左上選單 → APIs & Services → Library → 搜尋 Google Sheets API → Enable。

  3. 新增 Service Account

    IAM & Admin → Service Accounts → Create service account。名稱輸入 line-sheet-writer。本課不需給整個 Cloud Project 額外角色。

  4. 下載 JSON Key

    進入服務帳號 → Keys → Add key → Create new key → 選 JSON → Create。下載後不要上傳 GitHub。

  5. 共用試算表

    打開 JSON，複製 client_email。回 Google Sheet 按 共用，貼上該 email，權限選 編輯者，取消通知後送出。

  6. 轉成 Base64

    把 JSON 放在容易找到的位置；於該資料夾空白處按 Shift＋右鍵 → 在終端機中開啟，執行以下 PowerShell。把檔名改成你的實際檔名。

    Windows PowerShell
    [Convert]::ToBase64String([IO.File]::ReadAllBytes("service-account.json")) | Set-Clipboard

    剪貼簿中的長字串稍後放到 GOOGLE_SERVICE_ACCOUNT_JSON_BASE64。

建立 Gmail App Password

  1. 開啟兩步驟驗證

    Google Account → Security／安全性 → 2-Step Verification／兩步驟驗證，依指示完成。組織帳號若停用 App Password，請改用允許的個人測試帳號或詢問管理員。

  2. 新增 App Password

    打開 App Password 頁面，再次驗證身分；名稱輸入「LINE Project Memory」，按 Create／建立。

  3. 安全保存

    複製 16 碼密碼，稍後放到 GMAIL_APP_PASSWORD。顯示中的空格可保留，範本會移除；不要使用你的 Gmail 一般登入密碼。

如何驗證成功

  • messages 與 rooms 名稱完全小寫，欄位順序正確
  • Google Sheets API 顯示 Enabled
  • 服務帳號 client_email 是試算表編輯者
  • 已複製 Spreadsheet ID、Base64 JSON 與 Gmail App Password
