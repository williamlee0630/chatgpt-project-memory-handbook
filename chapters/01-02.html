第 1 章｜取得會議原始資料

1-2 Tactiq 轉錄與儲存至 Google Drive

讓 Tactiq 在 Google Meet 取得繁體中文逐字稿，會議處理完成後自動建立 Google Docs。

基礎篇10 分鐘Automatic 已實測成功
工具定位Tactiq 只負責即時轉錄、保存 Transcript、把完整逐字稿傳到 Drive。本課不使用 Tactiq AI Summary，不依賴 AI credits。
免費額度提醒2026/09 實測時，Tactiq Free 每帳號每月有 10 場 meeting transcripts，另有 5 AI credits；兩者是不同額度。本課主流程不使用 AI credits。免費方案與額度未來可能調整，請以 Tactiq 當下官方方案為準，不承諾永久免費。

開始前

  • Windows 電腦與 Chrome 或 Edge
  • Google 帳號，可使用 Meet 與 Drive
  • Tactiq 帳號

安裝 Tactiq 擴充功能開啟 Google Meet開啟 Tactiq

實作 A：取得繁中逐字稿

練習案例本節使用虛構的「活動籌備專案」，方便你在第 6 章繼續驗證日期變更與候選日期。

  1. 安裝並登入

    在 Chrome 線上應用程式商店按 加到 Chrome → 新增擴充功能。安裝後按瀏覽器右上角拼圖圖示 → 找到 Tactiq → 按圖釘固定；再點 Tactiq 圖示，登入你要保存會議的帳號並允許會議平台所需權限。如果首次設定要求選擇會議平台，請選擇 Google Meet。

    安裝 Tactiq 擴充功能

    你現在應該看到Chrome／Edge 工具列顯示 Tactiq 圖示；點開後是已登入狀態，Google Meet 在支援平台清單中。

  2. 建立測試 Meet

    到 Google Meet 按 發起新會議 → 發起即時會議 → 允許瀏覽器使用麥克風 → 進入會議。確認麥克風圖示不是紅色斜線。若 Tactiq 顯示 Enable 或 Fix Tactiq，依畫面允許擴充功能啟用；完成後重新整理 Meet 或離開後重新加入。

    開啟 Google Meet

  3. 選擇繁體中文

    在 Meet 右側 Tactiq 面板找到語言選單，選擇 Chinese / Mandarin Traditional。若面板未出現，先點瀏覽器工具列的 Tactiq 圖示；若仍沒有，重新整理或離開會議後重新加入。

  4. 念出測試句

    清楚說：「活動籌備專案的場地確認由活動窗口負責，四月十八日完成。」確認 Tactiq 面板出現文字。會議結束前再念一段：「公開報名日還沒有決定。」避免只測到單句。

    你現在應該看到Tactiq 面板隨說話新增中文文字；辨識可能有少量錯字，但兩段句子都應出現。

  5. 結束並確認 Transcript

    按 Meet 的紅色掛斷按鈕 → 開啟 Tactiq Dashboard → My Meetings → 點剛才的會議 → 確認 Transcript 區有兩段內容。

    開啟 Tactiq

    你現在應該看到My Meetings 有剛才的會議名稱與時間，點開後能搜尋「活動籌備專案」或「公開報名日」。

實作 B：Automatic Workflow 存入 Drive

  1. 先建立資料夾

    開啟 Google Drive → 左上 新增 → 新資料夾 → 輸入 會議原始紀錄 → 建立。雙擊資料夾確認可以打開。

    開啟 Google Drive

  2. 新增 Workflow

    開啟 Tactiq Dashboard → 左側 Workflows → + New Workflow → 選空白／Build from scratch。Workflow 名稱輸入 會議逐字稿自動存 Drive。

  3. 設定觸發

    執行方式選 Automatic，Trigger／Event 選 Meeting Processed。意思是 Tactiq 處理完會議後才執行，不是掛斷當下立即執行。

  4. 連接 Google Drive

    按新增步驟 → Share to an Integration → Google Drive。首次使用時按 Connect → 登入存放資料的 Google 帳號 → 檢查權限 → Allow／允許 → 回到 Workflow 選擇 會議原始紀錄 資料夾。

  5. 貼上 Liquid Template

    在 File name／檔名欄可填 {{ meeting.title }} - {{ meeting.date | date: "%Y-%m-%d" }}，讓檔名包含可區分會議的日期／時間或會議名稱，避免多場會議難以辨識；在文件內容／Body 欄貼上下列全文。這些雙大括號是本課現有流程使用的 Tactiq 動態變數，不需要學 Liquid 程式語言，也不要自行發明其他變數。

    Tactiq → Google Drive Liquid Template
    【會議名稱】
{{ meeting.title }}

【會議日期】
{{ meeting.date | date: "%Y-%m-%d" }}

【會議參與者】
{{ meeting.participantNames }}

【完整逐字稿】
{{ meeting.transcript }}

【Tactiq 原始紀錄】
{{ meeting.url }}

  6. 儲存並測試

    檢查資料夾與內容欄 → 按 Save。再開一場短 Meet 並說兩段中文 → 正常結束 → 到 My Meetings 確認 Transcript → 回 Workflows 的 Activity 查看執行狀態。不要先手動按 Run，等待 Tactiq 完成處理。

    你現在應該看到Workflow 名稱為「會議逐字稿自動存 Drive」，模式是 Automatic、事件是 Meeting Processed，Google Drive 動作指向「會議原始紀錄」，Activity 最後顯示成功。

Liquid 變數速查

變數寫入內容
{{ meeting.title }}會議名稱
{{ meeting.date }}會議日期；範本已轉成 YYYY-MM-DD
{{ meeting.participantNames }}參與者
{{ meeting.transcript }}完整會議逐字稿；寫入 Drive 已實測成功
{{ meeting.url }}Tactiq 原始紀錄連結

如何驗證成功

  • Tactiq My Meetings 看得到完整 Transcript
  • Workflow Activity 顯示執行成功
  • Drive 的 會議原始紀錄 出現新的 Google Docs
  • 打開 Docs，搜尋剛念的第二段句子；不是只有標題或連結
實測結果Automatic → Meeting Processed 已實測可在完全沒有手動按 Run 的情況下建立含完整 {{ meeting.transcript }} 的 Google Docs。

等待與備援

Tactiq 完成會議處理後會自動執行，實際時間可能有所延遲，教材不承諾固定 10～15 分鐘。若 My Meetings 已有 Transcript、Activity 仍沒有成功紀錄，再使用：

Tactiq → My Meetings → 選擇會議 → Run Workflow

避免重複文件Automatic 尚在等待時手動按 Run，之後 Automatic 又執行，可能建立兩份相同文件。先看 Activity，再決定是否手動執行。
