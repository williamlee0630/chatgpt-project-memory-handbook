第 1 章｜取得會議原始資料

1-2 Tactiq 轉錄與儲存至 Google Drive

先完成 Tactiq 與 Google Drive 自動化設定，最後只開一場 Google Meet，同時驗證繁中逐字稿與 Google Docs 自動建立。

基礎篇10 分鐘Automatic 已實測成功
工具定位Tactiq 只負責即時轉錄、保存 Transcript、把完整逐字稿傳到 Drive。本課不使用 Tactiq AI Summary，不依賴 AI credits。
本節流程Tactiq 安裝與登入 → Google Drive 建立「會議原始紀錄」→ Automatic Workflow 設定 → Google Meet 測試 → Tactiq Transcript → Google Drive Google Docs
免費額度提醒2026/09 實測時，Tactiq Free 每帳號每月有 10 場 meeting transcripts，另有 5 AI credits；兩者是不同額度。本課主流程不使用 AI credits。免費方案與額度未來可能調整，請以 Tactiq 當下官方方案為準，不承諾永久免費。

開始前

  • Windows 電腦與 Chrome 或 Edge
  • Google 帳號，可使用 Meet 與 Drive
  • Tactiq 帳號

安裝 Tactiq 擴充功能Google Meet（稍後測試）開啟 Tactiq

實作 A：完成 Tactiq 與 Google Drive 自動化設定

  1. 安裝並登入

    在 Chrome 線上應用程式商店按 加到 Chrome → 新增擴充功能。安裝後按瀏覽器右上角拼圖圖示 → 找到 Tactiq → 按圖釘固定；再點 Tactiq 圖示，登入你要保存會議的帳號並允許會議平台所需權限。如果首次設定要求選擇會議平台，請選擇 Google Meet。

    安裝 Tactiq 擴充功能

    你現在應該看到Chrome／Edge 工具列顯示 Tactiq 圖示；點開後是已登入狀態，Google Meet 在支援平台清單中。

  2. 確認 Google Meet 支援

    確認 Tactiq 已安裝、已登入，且 Google Meet 位於支援平台清單中即可。這一步只確認基本狀態，現階段還不用開啟 Meet；等 Automatic Workflow 儲存完成後，再進行最後的完整測試。

  3. 先建立資料夾

    開啟 Google Drive → 左上 新增 → 新資料夾 → 輸入 會議原始紀錄 → 建立。雙擊資料夾確認可以打開。

    開啟 Google Drive

  4. 新增 Workflow

    開啟 Tactiq Dashboard → 左側 My Workflows／Workflows → + New Workflow → 選空白／Build from scratch。Workflow 名稱輸入 會議逐字稿自動存 Drive。

  5. 設定觸發

    執行方式選 Automatic，Trigger／Event 選 Meeting Processed。意思是 Tactiq 處理完會議後才執行，不是掛斷當下立即執行。

  6. 連接 Google Drive

    按新增步驟 → Share to an Integration → Google Drive。首次使用時按 Connect → 登入存放資料的 Google 帳號 → 檢查權限 → Allow／允許 → 回到 Workflow 選擇 會議原始紀錄 資料夾。

  7. 貼上固定參數

    File name 與 Liquid Template 不需要自己重新輸入，直接從本講義複製貼上即可。在 File name／檔名欄可填 {{ meeting.title }} - {{ meeting.date | date: "%Y-%m-%d" }}，讓檔名包含可區分會議的日期／時間或會議名稱，避免多場會議難以辨識；在文件內容／Body 欄貼上下列全文。這些雙大括號是本課現有流程使用的 Tactiq 動態變數，不需要學 Liquid 程式語言，也不要自行發明其他變數。

    Tactiq → Google Drive Liquid Template
    【會議名稱】
{{ meeting.title }}

【會議日期】
{{ meeting.date | date: "%Y-%m-%d" }}

【會議參與者】
{{ meeting.participantNames }}

【完整逐字稿】
{{ meeting.transcript }}

【Tactiq 原始紀錄】
{{ meeting.url }}

  8. 儲存 Workflow

    檢查 Folder、File name 與文件內容／Body 欄後，按 Save。先不要開啟 Meet，也不要手動按 Run；下一個實作會用唯一一場測試會議觸發這套 Automatic Workflow。

    你現在應該看到Workflow 名稱為「會議逐字稿自動存 Drive」，模式是 Automatic、事件是 Meeting Processed，Google Drive 動作指向「會議原始紀錄」，而且已儲存完成。

Liquid 變數速查

變數寫入內容
{{ meeting.title }}會議名稱
{{ meeting.date }}會議日期；範本已轉成 YYYY-MM-DD
{{ meeting.participantNames }}參與者
{{ meeting.transcript }}完整會議逐字稿；寫入 Drive 已實測成功
{{ meeting.url }}Tactiq 原始紀錄連結

實作 B：用一場 Google Meet 完整測試

練習案例本節使用虛構的「活動籌備專案」，方便你在第 6 章繼續驗證日期變更與候選日期。前面的設定都已完成，現在只需要開一場 Google Meet，就能同時確認 Tactiq 逐字稿與 Google Drive 自動儲存是否正常。

  1. 開啟唯一一場測試 Meet

    到 Google Meet 按 發起新會議 → 發起即時會議 → 允許瀏覽器使用麥克風 → 進入會議。確認麥克風圖示不是紅色斜線。

    開啟 Google Meet

  2. 確認 Tactiq widget 與繁中

    確認 Meet 右側的 Tactiq widget 正常出現，並在語言選單選擇 Chinese (Traditional)。若 Tactiq 顯示 Enable 或 Fix Tactiq，依畫面允許擴充功能啟用；完成後重新整理 Meet 或離開後重新加入。若面板未出現，先點瀏覽器工具列的 Tactiq 圖示。

  3. 念出測試句

    清楚說：「活動籌備專案的場地確認由活動窗口負責，四月十八日完成。」確認 Tactiq widget 即時出現 Transcript。會議結束前再念一段：「公開報名日還沒有決定。」避免只測到單句。

    你現在應該看到Tactiq widget 隨說話新增中文文字；辨識可能有少量錯字，但兩段句子都應出現。

  4. 結束並等待 Meeting Processed

    按 Meet 的紅色掛斷按鈕正常結束會議，等待 Tactiq 完成處理。Automatic Workflow 的 Trigger 是 Meeting Processed，不是掛斷當下立即執行；先不要手動按 Run。

  5. 確認 Tactiq Transcript

    開啟 Tactiq Dashboard → My Meetings → 點剛才的會議 → 確認 Transcript 區有兩段內容。

    開啟 Tactiq

    你現在應該看到My Meetings 有剛才的會議名稱與時間，點開後能搜尋「活動籌備專案」或「公開報名日」。

  6. 確認 Workflow Activity

    回到 My Workflows／Workflows → Activity，確認「會議逐字稿自動存 Drive」已有剛才會議的執行紀錄，最後狀態顯示成功。

  7. 確認 Google Drive

    開啟 Google Drive → 進入 會議原始紀錄，確認新的 Google Docs 已自動建立。

    開啟 Google Drive

  8. 確認 Google Docs 內容

    打開剛建立的 Google Docs，完成最後檢查：

    • 文件有正常建立
    • 會議基本資訊正常
    • Transcript 已寫入
    • 不是空白文件，也不是只有標題卻缺少逐字稿
    完整資料流成功Google Meet → Tactiq → Automatic Workflow → Google Drive → Google Docs 已完整通過。Automatic → Meeting Processed 已實測可在完全沒有手動按 Run 的情況下建立含完整 {{ meeting.transcript }} 的 Google Docs。

延伸：使用 Microsoft Edge + Microsoft Teams

這是選用的替代會議平台操作，不會取代前面的 Google Meet 主線，也不是另一套必修 Workflow。

不用重新設定 Drive Workflow如果你前面已用某個 Tactiq 帳號完成 Automatic → Meeting Processed → Google Drive → 會議原始紀錄，改用 Edge 時，請登入與前面相同的 Tactiq 帳號，並先到 Dashboard → Workflows 確認原本的「會議逐字稿自動存 Drive」是否仍存在。若原 Workflow 存在，就直接沿用，不需要重新建立。Edge 仍需另外安裝 Tactiq 擴充功能並確認 Microsoft Teams 支援。

1. 在 Edge 安裝並確認帳號

  1. 開啟 Microsoft Edge。
  2. 安裝 Tactiq 擴充功能。
  3. 將 Tactiq 固定在工具列。
  4. 登入與前面 Chrome 相同的 Tactiq 帳號。
  5. 開啟 Tactiq Dashboard。
  6. 到 Workflows，確認原本的「會議逐字稿自動存 Drive」仍存在；不要重新建立 Workflow。

安裝 Tactiq for Microsoft Edge

你現在應該看到Edge 工具列有已登入的 Tactiq，Dashboard 也能看到前面建立的「會議逐字稿自動存 Drive」。

2. 使用 Teams 瀏覽器版測試

Teams 請使用瀏覽器版本課 Microsoft Teams 延伸操作以 Chrome／Edge 瀏覽器版為準，不使用 Teams Windows Desktop App 作為教學流程。
  1. 取得一個 Microsoft Teams Meeting 連結。
  2. 使用 Microsoft Edge 或 Chrome 開啟連結。
  3. 選擇 Continue on this browser／在此瀏覽器上繼續。
  4. 進入 Teams Meeting。
  5. 確認 Tactiq Setup／支援平台中已啟用 Microsoft Teams。
  6. 開啟 Teams Live Captions。
  7. 選擇正確的 Teams Spoken Language。
  8. 確認 Tactiq transcription language 與 Teams Spoken Language 保持一致。
  9. 清楚說兩段完整測試句，確認畫面開始出現文字。
  10. 結束會議。

3. 驗證既有 Workflow

Teams 測試結束後，不要重做實作 B；改用下列項目驗證原本的 Workflow：

  • Tactiq → My Meetings 看得到剛才的 Teams 會議
  • Transcript 有完整內容
  • Workflows → Activity 有新的執行紀錄
  • 原本 Google Drive 的 會議原始紀錄 出現新的 Google Docs
  • 打開文件，確認含完整 {{ meeting.transcript }}
你現在應該看到如果以上項目成功，代表 Google Meet 與 Microsoft Teams 都可以共用同一套 Tactiq → Automatic Workflow → Google Drive 資料保存流程。

等待與備援

Tactiq 完成會議處理後會自動執行，實際時間可能有所延遲，教材不承諾固定 10～15 分鐘。若 My Meetings 已有 Transcript、Activity 仍沒有成功紀錄，再使用：

Tactiq → My Meetings → 選擇會議 → Run Workflow

避免重複文件Automatic 尚在等待時手動按 Run，之後 Automatic 又執行，可能建立兩份相同文件。先看 Activity，再決定是否手動執行。
