第 5 章｜部署 LINE Bot 至 Vercel

5-1 設定環境變數

下載 Python 正式學生版，以 Vercel Drop 建立 Project，再填入六個環境變數並 Redeploy。學生主線不經 GitHub。

進階篇8 分鐘提供完整範本

下載正式學生 ZIP查看範本說明開啟 Vercel

一般學生不需要本機開發環境本流程不需要 Git、GitHub、Vercel CLI、Python、venv、pip、ngrok，也不需要在本機啟動 Flask。GitHub 只適合講師或後續長期維護，不是學生完成課程的必要條件。

用 Vercel Drop 建立 Project

  1. 下載正式學生 ZIP

    下載 LINE訊息整理Bot_課程正式版.zip。ZIP 根目錄直接包含 app.py、index.py、requirements.txt、vercel.json 與其餘正式 Python 檔案；不含真實 .env 或 Service Account JSON。

    下載正式學生 ZIP

  2. 登入 Vercel

    登入自己的 Vercel 帳號。課程只使用網頁操作。

  3. 開啟 Vercel Drop

    進入 Vercel 建立 Project 的 Drop 上傳區。

    開啟 Vercel

  4. 拖入 ZIP 或資料夾

    可直接拖入正式 ZIP；若介面要求資料夾，就先解壓縮，再拖入解壓後、直接看得到 app.py 的專案資料夾。

  5. 等待 Project 建立

    等待 Vercel 建立 Project。第一次因尚未設定環境變數而失敗屬於預期情況；Project 建立後繼續設定，不需重新 Drop。

填入六個環境變數

  1. 開啟 Environment Variables

    Vercel Project → Settings → Environment Variables，逐筆新增。Environment 至少勾選 Production。

  2. 貼入正式六個變數

    Name 大小寫必須完全一致；只有以下六個：

    環境變數名稱清單
    LINE_CHANNEL_SECRET
LINE_CHANNEL_ACCESS_TOKEN
GMAIL_ADDRESS
GMAIL_APP_PASSWORD
GOOGLE_SHEET_ID
GOOGLE_SERVICE_ACCOUNT_BASE64
NameValue 來源
LINE_CHANNEL_SECRETLINE Developers Basic settings；前後不可有多餘空白
LINE_CHANNEL_ACCESS_TOKENMessaging API 的 Channel Access Token
GMAIL_ADDRESS完整寄件 Gmail 地址
GMAIL_APP_PASSWORD移除顯示用空格的 16 碼 App Password，不是一般登入密碼
GOOGLE_SHEET_IDSheets URL 的 /d/ 與 /edit 之間，不能填整條網址
GOOGLE_SERVICE_ACCOUNT_BASE64自己的 Service Account JSON 轉成的單行 Base64

套用設定

  1. Redeploy

    六個環境變數儲存後，到 Project → Deployments → 選擇最新一筆 → Redeploy。只有重新部署後，Function 才會取得新設定。

如何驗證成功

  • Vercel Project 已由 Drop 建立
  • Environment Variables 恰有六個正式名稱
  • GOOGLE_SHEET_ID 不是整條網址
  • GMAIL_APP_PASSWORD 不是一般登入密碼且貼入前已移除空格
  • Service Account JSON 沒有放入 ZIP、GitHub 或公開畫面
  • 六個變數完成後已執行 Redeploy
若不小心公開密鑰只刪檔案不夠；先撤銷或重新發行受影響密鑰，再更新 Vercel 並 Redeploy。公開過的密鑰視同已洩漏。
