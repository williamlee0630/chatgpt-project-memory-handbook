6-2 完整測試與常見錯誤排除

用一個可判斷版本變更的案例，跑完 LINE → Flask → Vercel → Sheets → Gmail，再與 Drive 的會議逐字稿交給 ChatGPT。

進階篇10 分鐘Drive + Gmail 已實測成功

完整測試腳本

  1. 準備會議當下版本

    開 Google Meet，讓 Tactiq 記錄：「第一版由小美負責，10/20 完成。上架日尚未決定。」正常結束並等待 Automatic Workflow 把完整 Transcript 寫入 Drive。

  2. 準備 LINE 會後更新

    在對應 LINE 群組輸入：「第一版期限改為 10/23，小美負責不變。」再輸入：「10/30 可以當候選上架日。」

  3. 寄出 LINE 紀錄

    輸入 #寄出紀錄，確認 Gmail 收到主旨 [LINE紀錄][群組名稱] 日期，正文有兩句對話。

  4. 驗收 Google Sheets

    核對兩列的 group_id 屬於目前群組、message 保留原文；Gmail 成功後兩列的 sent = TRUE。

  5. 執行跨來源 Prompt

    到 ChatGPT 專案，使用完整版 Prompt，指定專案與日期範圍，讓 Google Drive + Gmail → ChatGPT。

    開啟並複製 Prompt

  6. 核對判斷

    答案應列出決策變更 10/20 → 10/23；小美仍是負責人；10/30 只能在未決／候選，不得列為已確認上架日。

  7. 核對實際資料來源揭露

    最後必須列出本次實際讀取的 Google Drive 文件與 Gmail 郵件。任一來源無法存取時，答案必須說明，不能假裝完成。

建立每日工作記憶排程（選用）

完整跑通 LINE Bot → Gmail 並完成上方驗收後，可把下方 Prompt 建立成每天執行的 ChatGPT Scheduled Task／排程；課程示範可設每天晚上 8:00，實際時間可自行修改。

失敗時怎麼查

不要一次重設所有帳號。先記下最後一個成功節點，再到排錯中心依 A～J 情境檢查 Base64、Sheets 權限、Gmail SMTP、Vercel、LINE 與 ChatGPT 來源。

開啟 A～J 排錯情境

常見限制

  • Bot 只能取得加入後的新文字訊息，不會補抓歷史。
  • 本範本主線處理文字；圖片、貼圖、檔案與語音需另行設計。
  • 刪除或收回 LINE 訊息不一定能同步移除已保存紀錄。
  • 免費額度、App Password、LINE／Vercel／Tactiq 政策可能調整，以官方當下頁面為準。
  • Automatic Workflow 可能延遲；手動 Run 是備援，但太早執行可能重複。
