# 服務 3：更新最新專案工作記憶

使用者只需說「幫我更新專案」。確認本次專案、允許來源、資料期間與更新起點；同一對話中已確認的設定可沿用，無法確認時逐項詢問。重新讀取指定來源正文；既有同專案工作記憶只用來比較前後版本。

1. 將允許來源逐項標記為已讀且相關、已存取但無相關資料、目前無法存取、或期間尚未發生。Google Drive 的 Tactiq／Google Meet 文件與 Gmail `[LINE紀錄]` 郵件都必須讀正文。
2. 只納入本次期間、指定專案的事件。會議當下版本與後續 LINE／Email 明確變更分開，保留跨更新期間的舊版本 → 新版本、來源、日期；較晚的建議不改寫決策。
3. 更新最新已確認決策、待辦、負責人、期限、進度、風險與未決事項。完成需要證據，缺少關鍵資訊標未指定或人工確認；資訊衝突不自行裁定。
4. 列出本次資料範圍、每個來源的狀態、實際讀到及排除的資料。只有來源確實讀取且輸出經使用者驗收，才可按 `settings.md` 推進成功更新截止日。

## 固定輸出格式

```text
# 30 秒摘要
# 最新已確認決策
# 待辦事項
| 事項 | 負責人 | 期限 | 狀態 |
| --- | --- | --- | --- |
# 決策變更
# 未決事項
# 衝突提醒
# 需要人工確認
# 本次資料範圍與來源狀態
- 指定日期範圍：
- 實際已發生檢查範圍：
- 尚未發生的未來期間：
- 各允許來源狀態：
# 本次實際讀取的資料
## Google Drive／會議來源
## LINE／Gmail／使用者提供來源
# 本次排除的資料
```

沒有內容的章節可填「未見明確紀錄」或「無」，不可補推測。教學示例可按需查看 `../assets/examples/seminar.md`；示例不算本次來源。
