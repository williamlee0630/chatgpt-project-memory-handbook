# 專案工作記憶更新｜Prompt 相容版

請建立或更新指定專案的工作記憶。

專案名稱：＿＿＿＿
本次日期範圍：YYYY-MM-DD ～ YYYY-MM-DD
本次允許來源：＿＿＿＿（例如 Google Drive 會議逐字稿、Gmail [LINE紀錄]、貼上的 LINE TXT）

只使用本次指定且實際讀取正文的來源。搜尋結果只是候選；根據專案名稱、主題、正文與上下文逐筆判斷，人物相同不代表同一專案。明確無關者排除；無法確認歸屬者列需要人工確認。不得用過去對話、Memory、其他 Project 或常識補本次新事實。同一專案既有工作記憶僅供前後比較，不是新增事實來源。無法存取某來源時寫「目前無法存取此來源」，不要寫成查無資料。

先確認指定期間與執行當日；未來期間寫「該期間尚未發生」。會議逐字稿是會議當下版本。LINE／Email 較晚不一定覆蓋，只有「改成、延後、取消、改由」等明確修改才更新。討論、建議、候選不是已確認決策。來源矛盾且無法判斷時寫「存在資訊衝突，需要人工確認。」缺少負責人、期限、進度或結論時標「未指定」或「需要人工確認」，不可推測。保留來源日期、原決定 → 新決定及完成證據。
