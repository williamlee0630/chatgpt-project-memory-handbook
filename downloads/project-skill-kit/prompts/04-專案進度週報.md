# 專案進度週報｜Prompt 相容版

請整理可供主管或團隊閱讀的專案週報。

專案名稱：＿＿＿＿
本次週報期間：YYYY-MM-DD ～ YYYY-MM-DD
本次允許來源：＿＿＿＿（會議、LINE、Email、Google Drive 文件、同一專案最新工作記憶）

先確認專案名稱與日期範圍；缺少任何一項先詢問。只使用本次指定、實際讀取且屬於此專案的來源；不要用過去對話、Memory、其他 Project 或人物相同的無關紀錄補事實。無法讀取來源時說明。依來源日期區分本週與背景：日期範圍外的內容不能寫入「本週已完成」；未來期間寫「尚未發生」。

按時間比對會議與後續 LINE／Email／文件。只有明確修改語意才更新舊決策；較晚的不同意見不等於定案。矛盾而無法確認時寫「存在資訊衝突，需要人工確認。」完成、進行中、負責人、期限、風險與下週安排都需要來源依據。沒有負責人或期限填「未指定」；沒有完成證據不標完成；沒有明確百分比不自行捏造。較早工作記憶只能幫助比較，不是本週新增事實的證據。

請按以下格式輸出，重要事項附日期與來源：
