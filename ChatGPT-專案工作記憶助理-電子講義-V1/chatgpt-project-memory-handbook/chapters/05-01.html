第 5 章｜部署 LINE Bot 至 Vercel

5-1 設定環境變數

把課程範本推到 GitHub，再把 7 個設定值安全放入 Vercel。密鑰不寫入程式碼。

進階篇8 分鐘提供完整範本

開啟 LINE Bot 範本說明建立 GitHub RepositoryVercel New Project

把範本放到 GitHub

  1. 下載課程資料夾

    取得電子講義附帶的 downloads/line-bot-starter。確認裡面有 api/webhook.js、lib、package.json 與 vercel.json。

  2. 建立 Repository

    GitHub → New repository；名稱輸入 line-project-memory-bot，Visibility 選 Private，先不要勾選額外 README，按 Create repository。

  3. 上傳檔案

    在空 Repository 按 uploading an existing file，把範本資料夾內的檔案與資料夾拖入。確認沒有 .env、service-account.json 或真實密鑰，按 Commit changes。

匯入 Vercel

  1. Import Git Repository

    Vercel → Add New… → Project → 找到 line-project-memory-bot → Import。Framework Preset 可維持 Other。

  2. 展開 Environment Variables

    在部署前頁面找到 Environment Variables，逐筆新增。Environment 勾 Production、Preview、Development，或至少 Production。

7 個環境變數

NameValue 來源
LINE_CHANNEL_SECRETLINE Developers Basic settings
LINE_CHANNEL_ACCESS_TOKENMessaging API 的 Channel Access Token
GOOGLE_SERVICE_ACCOUNT_JSON_BASE64PowerShell 轉換後的長字串
GOOGLE_SHEET_IDSheets URL 的 /d/ 與 /edit 之間
GMAIL_USER寄件 Gmail 完整地址
GMAIL_APP_PASSWORD16 碼 App Password
SEND_COMMAND!寄送紀錄

如何驗證成功

  • GitHub Repository 不含真實密鑰與 service-account.json
  • Vercel Environment Variables 有 7 筆且 Name 大小寫完全相同
  • GOOGLE_SHEET_ID 不是整條網址
  • GMAIL_APP_PASSWORD 不是一般登入密碼
若不小心上傳密鑰只刪檔案不夠；先撤銷／重新發行受影響密鑰，再更新 Vercel。公開過的密鑰視同已洩漏。
