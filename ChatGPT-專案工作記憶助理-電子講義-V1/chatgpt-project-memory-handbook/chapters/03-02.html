基礎篇7 分鐘核心實作

判斷規則

訊號處理方式
決定、確認、照此執行有清楚上下文時列為已確認決策
改為、延期至、取消、改由與原決定對照，列「原決定 → 新決定」
候選、暫定、考慮、建議、可能、預計保留為未決／候選，不得定案
兩邊矛盾但不確定新版列衝突提醒，不猜
缺負責人或期限欄位寫「待確認」

執行 Prompt

基礎版可直接使用附錄的 Prompt，將「搜尋 Gmail」那段改成「讀取我上傳的 LINE TXT」。

開啟可複製 Prompt

人工驗收

  1. 抽查每個決策

    回到原文搜尋關鍵句，確認有明確定案語意。

  2. 抽查每個待辦

    事項、負責人、期限都必須在來源中找得到；缺一項就待確認。

  3. 檢查版本變更

    每筆變更必須同時指出原決定、新決定與各自來源。

  4. 檢查候選

    搜尋「候選、暫定、可能、預計」等詞，確認未被放進已確認決策。

  5. 保存專案進度

    把本次確認後的結果存回固定專案，下一次整理時指定新日期範圍，再延續更新。

人是最後一關ChatGPT 可協助找證據，但不能代表團隊正式定案。尤其日期、金額、客戶承諾與發布時程，必須回到來源或詢問當事人。
