第 5 章｜部署 LINE Bot 至 Vercel

5-2 部署、Webhook 與驗證

取得公開 HTTPS 網址、填入 LINE Webhook URL，先 Verify，再測群組與 Google Sheets。

進階篇12 分鐘完整串接

部署 Vercel

  1. 按 Deploy

    在上一節的 Vercel 匯入頁確認 Environment Variables 後按 Deploy。等待出現 Congratulations／Ready。

  2. 複製 Domain

    開啟 Project → Deployments → 最新部署，複製類似 https://line-project-memory-bot.vercel.app 的 Production Domain。

  3. 檢查函式

    在瀏覽器開啟 Domain 加 /api/webhook。GET 成功應顯示 LINE Bot is running。這只證明 Vercel 函式存在，尚未證明 LINE 簽章與 Sheets。

設定 LINE Webhook

  1. 組合 Webhook URL

    格式為：

    替換成你的網域
    https://你的-vercel-domain.vercel.app/api/webhook

  2. 貼入 LINE Developers

    回 Channel → Messaging API → Webhook settings → Edit，貼上 URL → Update。

  3. 啟用並 Verify

    將 Use webhook 設為 Enabled，再按 Verify。成功應顯示 Success。

測試順序

  1. 把 Bot 加入測試群組

    使用 Messaging API 頁面的 QR code 加官方帳號好友，再把它邀入測試群組。

  2. 查詢 groupId

    在群組輸入 !群組ID。Bot 應回覆以 C 開頭的 groupId。此指令不寫入 messages。

  3. 送出一般文字

    輸入「測試專案：第一版 10/20 完成」。打開 Sheets 的 messages 分頁，應新增一列，groupId、text 有值，sentAt 空白。

  4. 檢查 Vercel Logs

    若沒有新增列：Vercel Project → Logs，篩選最新 Function invocation。先看明確錯誤，不要反覆重設所有密鑰。

如何驗證成功

  • Webhook URL 是 HTTPS 且以 /api/webhook 結尾
  • LINE Verify 顯示 Success
  • Bot 能在群組回覆 !群組ID
  • 一般文字會新增至 messages；sentAt 暫時空白
修改變數後要重新部署Vercel Environment Variables 更新不一定會套用到已存在的部署。更新後到 Deployments 重新 Deploy，再次 Verify。
