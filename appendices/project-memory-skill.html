3. 第一次啟動與互動示範

只輸入啟動指令時，助理會用文字詢問：「請問今天想完成什麼工作？」並列出 1 整理會議、2 確認決策變更、3 更新最新工作記憶、4 產生週報。輸入 3，即可開始工作記憶流程；直接說「幫我產生本週週報」則直接進入週報，不重問服務類型。

活動籌備專案：第一次使用

  1. 你說：3。助理確認專案；若不知道，問「這次要整理哪個專案？」你回答「活動籌備專案」。
  2. 助理確認日期；若不知道，問「你想整理哪個期間？」可選本週、上週、從上次成功更新後到今天、從指定來源的實際紀錄日期辨識，或自訂日期。你選擇根據已指定來源的紀錄日期，再確認助理提出的範圍。
  3. 助理確認本次允許來源；若不知道，問「這次要使用哪些資料？」請指定 Codex 能讀的會議與 LINE 文字檔或資料夾。若無法讀取 ChatGPT Project 中的 Drive／Gmail，就提供01_meeting.txt 和 02_line_email.txt。
  4. 助理讀取兩份正文並輸出工作記憶。下載練習檔的固定答案是期限 2026-04-18 → 2026-04-21，活動窗口仍負責，2026-04-25 只是候選日；最後核對實際來源。

4. 同專案快速使用、換專案與設定

同一個已確認專案，第二次可直接說「更新一下專案」或「幫我產生本週週報」。助理只在必要資訊缺失時追問；每次仍重新讀本次允許來源正文。前次 AI 回答或既有工作記憶只能幫助比較，不是新事實。新對話或換專案時，重新確認專案、允許來源與日期範圍，不能混入舊專案。

想在下次對話沿用設定時，可以說「我同意把這個專案的非敏感設定儲存在【此專案可寫入的工作資料夾】」。助理只保存專案名稱、非敏感來源參照、時區及已驗收的成功截止日；更新失敗時不能推進日期，也不保存密碼或 Token。想清除時說「清除目前專案的工作助理設定」，助理先核對專案與檔案位置，只清除該專案設定。若沒有持久化能力，只能沿用目前對話確實可確認的設定。

5. 資料正確性與使用限制

  • 只處理目前指定專案、期間及本次允許的已讀來源，其他專案排除。
  • 搜尋結果、檔名及郵件主旨只是候選，必須打開正文。
  • 會議是當下版本；較晚討論不自動覆蓋。建議與候選保留未決。
  • 完成、負責人、期限與下週安排需有來源證據；資訊衝突列需要人工確認。
  • 無法存取來源時明說並要求提供，不假裝已讀。
課程中的自動化範圍指定來源自動收集＋固定週期重新搜尋與整理＋形成最新版工作記憶。紙本、錄音或無權存取的系統須先數位化或匯入。Skill 不會自動開通資料權限，也不保證把結果永久寫入 ChatGPT Project。

6. 沒有 Skill：四份 Prompt 相容版

Prompt = 全員可使用的核心版本；Skill = 將同一套流程封裝成更方便重複使用的進階版本。沒有 Skill 功能也可以在 ChatGPT Project 用已授權的 Google Drive／Gmail 或上傳檔案操作。首次使用先從下方四份完整版選一份，填入專案、日期與允許來源；完整的來源判斷、衝突處理及輸出格式都保留。原本三張課程主流程 Prompt也維持原用途。

同一對話後續更新簡短版

只在專案、允許來源、規則與上次成功截止日已確認時使用。沿用規則不等於把前次回答當最新證據；本次新事實仍須重新讀取指定來源。若開新對話、換專案或缺少設定，先使用完整版或補充資訊。
