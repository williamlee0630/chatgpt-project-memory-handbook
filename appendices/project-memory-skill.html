本課程仍以 Prompt 為主要教學方式。Skill 是將前面已學過、已測試過的跨來源工作記憶整理規則進一步封裝，方便在支援 Skills 的環境中重複使用。

1. Skill 是什麼？

前面的課程使用「跨來源工作記憶 Prompt」，把 Google Meet／Tactiq 紀錄存入 Google Drive，把 LINE 工作紀錄送到 Gmail，再由 ChatGPT 整理 30 秒摘要、最新決策、待辦、負責人、期限、決策變更、未決事項、衝突提醒與需要人工確認的內容。

Skill 使用相同的整理邏輯，只是把固定規則預先封裝。它不取代 Prompt，也不改變 Google Drive、Gmail、LINE Bot 或排程的主流程。

3. Skill 固定執行規則

  • 只處理目前指定的專案與本次允許來源
  • 先確認本次指定日期範圍
  • 不把其他專案資料混入
  • 必須實際讀取來源內容，不只看檔名或搜尋摘要
  • Google Meet／Tactiq 紀錄視為「會議當下版本」
  • 後續 LINE 紀錄若出現明確新決定，可以更新較早資訊
  • 既有工作記憶只用於同一專案的前後比較，不作為本次新增事實來源
  • 保留重要的決策變更
  • 無法判斷時不可自行猜測
  • 缺少負責人、期限或結論時不可自行補資料
  • 來源互相衝突而無法判斷時，列為「需要人工確認」

4. Skill 需要哪些輸入？

輸入範例
專案名稱研討會討論紀錄
日期範圍2026/09/14～2026/09/20

可使用的資料來源

  • Google Drive 中的 Tactiq／Google Meet 紀錄
  • Gmail 中主旨包含 [LINE紀錄] 的工作紀錄
  • 使用者直接上傳的會議紀錄
  • 使用者直接貼上的 LINE 紀錄
不可假裝已讀取Skill 不應在沒有 Google Drive／Gmail 權限的情況下假裝已經讀取資料。如果無法存取來源，應清楚說明限制，並要求使用者提供、上傳或貼上資料後再整理。
